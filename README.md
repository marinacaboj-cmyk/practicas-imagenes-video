# Bitácora de la práctica: Imágenes y vídeo con herramientas de Google

**Asignatura:** Informática para el Trabajo Social

**Tema de la página web:** La soledad no deseada en las personas mayores

## 1. Introducción

En esta práctica he creado una página web sobre la soledad no deseada en las personas mayores, utilizando GitHub para publicarla, Gemini para generar las imágenes y Google Vids para elaborar un vídeo.

El objetivo de la página es sensibilizar sobre esta problemática social y mostrar la importancia del acompañamiento, las relaciones sociales y la intervención desde el Trabajo Social.
